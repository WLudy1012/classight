# 课程表插件

在管理后台「插件管理」启用课程表后，登录成员可从班级中心查看周课表。具有 `timetable.manage` 权限的用户可以编辑；该权限可通过角色管理分配。

每份课表包含一个学期：设置第一周周一、总周数和节次时间，再添加课程的星期、起止节次、起止周、单双周、教师与地点。支持按周切换、返回当前周和 JSON 导入导出。导入的数据需要再次保存才对其他成员可见；导入会替换当前编辑内容，不会自动合并。

同一日期周次与节次的重叠课程会被拒绝；单双周不重合的课程可以共用同一时段。保存使用版本号防止覆盖并发修改；发生版本冲突时需要退出编辑并重新加载。为了兼容现有数据库字段，序列化后的课表数据最多 60,000 字节。

课程表采用内置插件注册并存储在数据库的设置表中，不需要新增数据库迁移。停用插件会阻止课表接口访问，但不会删除已保存的数据。模拟模式数据仅保存在浏览器本地，不能代替后端持久化。
