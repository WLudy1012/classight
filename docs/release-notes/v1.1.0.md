# Classight v1.1.0

本次更新完善自动更新流程，并加入班会审核闭环、班级博客、班级群聊和主页粒子动效。

**Linux 升级前请先安装 ASP.NET Core 11.0.0 正式版运行时。原 RC2 运行时无法运行本版本。Windows 自包含包已包含所需运行时。**

SDK 和 ASP.NET Core 依赖升级到 .NET 11 正式版，修复 RC2 所受的 [CVE-2026-114149](https://github.com/advisories/GHSA-x33c-w48q-qrgc) 拒绝服务漏洞。

## 自动更新

- 系统状态页增加程序更新区域，可查看版本、下载进度、失败原因、下次检查时间，并手动检查更新。
- 更新失败默认 15 分钟后重试，检查间隔和下载超时可在 `config/appsettings.json` 中设置。
- Windows 单 EXE 自带 .NET 更新助手，无需 PowerShell，在当前程序退出后校验并安装待更新文件，再次启动生效。
- Linux 替换程序前保留旧可执行文件，重启服务后运行新版。备份不包含数据库。
- 修复系统状态页始终显示固定版本号的问题。

## 班级功能

- 班会提交内容和课件按个人或小组隔离，支持审核通过、退回和修改后重新审核。管理员主动开启对外展示后，访客才能查看；展示可撤销并会过期。
- 管理员可以手动建立小组、分配成员并调整分组。
- 新增班级博客 DLL 插件，支持个人草稿、班内发布、撤回、搜索和管理员管理文章。
- 新增班级群聊 DLL 插件，支持班内消息、历史记录、本人撤回和管理员删除。

## 主页

- 粒子支持惯性、涡流和阻尼回弹，无操作时也持续缓慢流动。
- 加入移动光源、球面高光、字形明暗和柔和投影。
- 隐藏页面时暂停粒子计算，适配低画质及“减少动态效果”。

## 安装与升级

- Windows x64：下载 `Classight-Windows-x64.zip` 或单文件 `ClassightDaemon-win-x64.exe`，包含 .NET 运行时。
- Linux x64：下载 `ClassightDaemon-linux-x64`，可重命名为 `ClassightDaemon`；需要 ASP.NET Core 11.0.0 或更高的 11.0 正式版运行时。
- 每个下载文件附带 SHA-256 校验文件。更新保留原有 `config/`、数据和自定义插件。
- 现有版本开启自动更新后会检查本次发布；Windows v1.0.x 仍通过原启动脚本安装此次更新。升级至 v1.1.0 后，单 EXE 启动也支持后续更新。

详细配置与恢复方式见[安装与自动更新](https://github.com/WLudy1012/classight/blob/v1.1.0/docs/releases.md)。
